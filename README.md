# sistemabancario
Este projeto é um sistema bancário desenvolvido com a linguagem Python, com interação pelo terminal. O programa simula operações básicas em um banco, permitindo login e escolha entre saque e depósito.
Esse trabalho tem como objetivo de praticar programação em Python, estrutura de repetição, entrada de dados e conversão de tipos.
Feito pelo Google Colab como ambiente para desenvolvimento
